GitHub↗

First Principle

The Agent is only as useful as the boundaries around it are clear.

01

Safety is independent

An external governor bounds and interrupts every action.

02

Simulation before hardware

Real-world tests begin only after simulation gates pass.

03

Every action is observable

Observations, decisions, failures and recovery remain logged.

Agent Loop

From raw signals to measurable behavior, each layer contributes a distinct part of the Agent system.

01 / DATA

Physical experience

RGB-D, proprioception, trajectories and simulation logs.

02 / MODELS

World & action

VLA model, world model and spatial policy.

03 / TRAINING

Learn to act

Imitation learning, simulation RL and Sim2Real adaptation.

04 / INFERENCE

Real-time control

Low-latency perception, planning and action chunks.

05 / HARNESS

Physical safety

Robot SDK, simulator, safety governor and fleet control.

06 / EVAL

Real-world reliability

Task success, safety, robustness and sim-to-real gap.
